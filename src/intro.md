# 这套课怎么学（写给架构师 / 售前视角）

你不跑实验。这套课对你的价值不是复现数字，而是四件可以立刻变现的能力：

1. **机制心智模型**——任何一个推理/训练优化，都能说出它解决什么问题、不动它会发生什么。
2. **容量测算**——显存、KV Cache、成本，用公式和量级现场推导，而不是背结论。
3. **选型决策**——swap 还是重算、ZeRO 选几级、TP/PP/DP 怎么组合，给出判断依据。
4. **讲清楚**——把机制翻译成客户/领导听得懂的一句话。
